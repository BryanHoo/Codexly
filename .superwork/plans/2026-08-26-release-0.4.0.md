# Feature Implementation Plan

**Goal:** 发布 `@bryanhu/codexly@0.4.0`，同步版本日志、发布包、npm 包与 GitHub Release。

**Suggested Spec Reads:**

- `.superwork/spec/guides/index.md` — 定义发布包、打包顺序和质量门禁。
- `.superwork/spec/shared/quality-guidelines.md` — 定义 Release 测试约束。
- `docs/releasing.md` — 定义标签、Trusted Publisher 和失败恢复流程。

**Architecture:** 复用 tag 驱动的 `release.yml`。本地完成发布资料、完整验证、clean build 与 tarball 检查后提交并推送 `main` 和 annotated tag，由 GitHub Actions 使用 `pnpm pack` 与 npm Trusted Publisher 发布。

**Tech Stack:** pnpm、npm、Git、GitHub Actions、GitHub CLI

## Global Constraints

- 仅发布根包 `@bryanhu/codexly`，内部 Workspace 包保持私有 `0.0.0`。
- `package.json`、annotated tag、npm 版本与 GitHub Release 必须统一为 `0.4.0`。
- 发布对象必须由 clean build 后的 `pnpm pack` 生成，再由 npm CLI 发布。
- 提交信息必须使用中文 Conventional Commits，并包含必填 scope。

### Task 1: 更新 0.4.0 发布资料

**Files:**

- Modify: `package.json`
- Modify: `CHANGELOG.md`
- Create: `.superwork/plans/2026-08-26-release-0.4.0.md`

**Interfaces:**

- Consumes: `v0.3.0..HEAD` 提交记录
- Produces: `ReleaseMetadataV0.4.0`

**Behavior:**

- 将根包版本更新为 `0.4.0`，记录工作台背景、性能诊断、运行时优化和用户可见修复。

**Stop Conditions:**

- 若包版本、日志版本或发布日期不一致，停止发布。

- [x] **Task Status:** completed

Run: `pnpm exec prettier --check package.json CHANGELOG.md .superwork/plans/2026-08-26-release-0.4.0.md && node ./tools/extract-release-notes.mjs 0.4.0 /tmp/codexly-0.4.0-release-notes.md`

Expected: 发布资料格式正确，且可提取非空 `0.4.0` Release Notes。

### Task 2: 验证并打包发布候选

**Files:**

- Test: `dist/**`
- Test: npm tarball for `@bryanhu/codexly@0.4.0`

**Interfaces:**

- Consumes: `ReleaseMetadataV0.4.0`
- Produces: `VerifiedReleaseCandidateV0.4.0`

**Behavior:**

- 执行完整质量门禁、浏览器 E2E、clean build 与发布包校验，并生成可检查的 tarball。

**Stop Conditions:**

- 任一质量门禁、E2E、构建或包清单校验失败时停止发布。

- [x] **Task Status:** completed

Run: `pnpm check && CI=1 pnpm test:e2e && pnpm run build:clean && pnpm run bundle:check && pnpm run package:check && pnpm pack --out /tmp/codexly-0.4.0.tgz`

Expected: 全部门禁通过，tarball 清单和 manifest 均为可发布的 `@bryanhu/codexly@0.4.0`。

### Task 3: 提交并触发 0.4.0 发布

**Files:**

- Modify: Git history on `main`
- Create: annotated Git tag `v0.4.0`

**Interfaces:**

- Consumes: `VerifiedReleaseCandidateV0.4.0`
- Produces: `ReleaseWorkflowRunV0.4.0`

**Behavior:**

- 提交并推送 `main` 与 `v0.4.0`，等待 Release workflow 完成 npm 与 GitHub 发布。

**Stop Conditions:**

- 远端出现未包含提交、标签已存在或流水线需要外部审批时停止。

- [ ] **Task Status:** pending

Run: `gh run watch --exit-status`

Expected: Release workflow 成功完成。

### Task 4: 核验远端发布结果

**Files:**

- Test: GitHub Release `v0.4.0`

**Interfaces:**

- Consumes: `ReleaseWorkflowRunV0.4.0`

**Stop Conditions:**

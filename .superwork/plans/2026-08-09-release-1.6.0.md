# Feature Implementation Plan

**Goal:** 发布 `@bryanhu/code-agent@1.6.0`，同步用户文档并完成 npm 与 GitHub Release 发布。

**Suggested Spec Reads:**

- `.superwork/spec/guides/index.md` — 约束版本验证、打包和发布方式。
- `docs/releasing.md` — 定义仓库的标签、OIDC 和 GitHub Release 流程。

**Architecture:** 先准备版本元数据和双语文档，再执行完整质量门禁与 tarball 检查，最后提交、打标签并由 GitHub Actions 发布 npm 包和 GitHub Release。

**Tech Stack:** pnpm、npm、Git、GitHub Actions、GitHub CLI。

## Global Constraints

- 仅发布根包 `@bryanhu/code-agent`，内部 Workspace 包保持私有。
- 版本标签必须与 `package.json` 完全匹配。
- 发布必须使用 `pnpm pack` 生成 tarball，并由现有 GitHub Actions OIDC 流程执行 `npm publish`。
- 提交信息必须遵循仓库规定的中文 Conventional Commits 格式。

### Task 2: 验证并打包发布产物

**Files:**

- Test: `package.json`
- Test: `pnpm-lock.yaml`
- Test: `tools/verify-package.mjs`
- Test: `tests/e2e/**`

**Interfaces:**

- Consumes: `ReleaseMetadataV1.6.0`
- Produces: `VerifiedTarballV1.6.0`

**Behavior:**

- 运行完整检查、端到端测试与本地打包，确认 tarball 不含 Workspace 协议、源码映射或意外文件。

**Stop Conditions:**

- 任一质量门禁、端到端测试或打包校验失败时停止发布。

- [x] **Task Status:** completed

Run: `pnpm check && pnpm test:e2e && pnpm pack --out /tmp/code-agent-1.6.0.tgz`

Expected: 所有检查通过并生成 `code-agent-1.6.0.tgz`。

# Feature Implementation Plan

**Goal:** 发布 `@bryanhu/codexly@0.2.0`，同步版本文档、构建产物、npm 包与 GitHub Release。

**Suggested Spec Reads:**

- `.superwork/spec/guides/index.md` — 定义发布包、打包顺序和质量门禁。
- `.superwork/spec/shared/quality-guidelines.md` — 定义 Release 运行时与测试隔离规则。
- `docs/releasing.md` — 定义标签、Trusted Publisher 和失败恢复流程。

**Architecture:** 复用 tag 驱动的 `release.yml`，本地完成发布资料与完整验证后提交并推送 `main` 和 annotated tag，由 GitHub Actions 使用 `pnpm pack` 与 npm Trusted Publisher 发布。

**Tech Stack:** pnpm、npm、Git、GitHub Actions、GitHub CLI

## Global Constraints

- 仅发布根包 `@bryanhu/codexly`，内部 Workspace 包保持私有 `0.0.0`。
- `package.json`、annotated tag、npm 版本与 GitHub Release 必须统一为 `0.2.0`。
- 发布对象必须由 `pnpm pack` 生成，再由 npm CLI 发布。
- 提交信息必须使用中文 Conventional Commits，并包含必填 scope。

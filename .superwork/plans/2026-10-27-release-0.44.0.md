# Feature Implementation Plan

**Goal:** 发布 Codexly 0.44.0，统一 Web/npm 与桌面版本，更新中英文用户文档并核验联合发行物。

**Suggested Spec Reads:**

**Architecture:** 沿用根更新日志和 GitHub Actions 联合发布，仅修改版本元数据与既有文档。

**Tech Stack:** Node.js 24、pnpm 11.22.0、Rust/Tauri、Markdown、GitHub Actions。

## Global Constraints

- 根 package、桌面 package、Tauri、Cargo 与 Cargo lock 统一为 0.44.0；新增兼容功能提升次版本号。
- 文档面向现有用户，沿用操作指南和参考的既有结构；中英文同步，桌面原生功能明确平台边界。
- 日志保留历史、日期及对比链接；本版归纳为 6 条，不复制工程实现细节。
- 不新增业务实现或重复测试；复用既有版本、日志、打包和跨端测试。
- 使用 Python3 3.11+ 与 pnpm；不提交本机路径、凭据、日志或构建产物。
- 用户已授权发布，提交使用 `chore(release): 发布 0.44.0 并更新使用文档`，原子推送 main 与注释标签。
- 所有本地门禁通过后推送；远端 Release 成功、npm 可读取且安装包、更新清单和签名齐全才算发布完成。

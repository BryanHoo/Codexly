**Goal:** 全量切换到共享 ACP 接入，迁移两端配置、聊天和历史续聊。

**Suggested Spec Reads:**

**Architecture:** 官方 ACP v1 SDK 与官方 agent adapter；核心使用稳定 v1，供应商配置显式协商 v1 providers 可选草案，通过 SDK /unstable 入口启用；Web 和桌面复用 TypeScript Provider，经原有 HTTP/Tauri 交付。

**Tech Stack:** TypeScript、Node 24、ACP SDK 2.4.0、pnpm 11、Vitest、React、Tauri/Rust。

## Global Constraints

- 保留应用任务 ID 和原始历史，不静默创建替代会话，不自动重试不确定的 prompt。
- 业务数据继续使用 ~/.codexly；SQLite 不阻塞主线程；不逐 token 全量复制或持久化。
- 两端共享能力与界面逻辑，桌面不绕行 HTTP；关键执行边界有中文注释。
- 只实现 ACP 接口，厂商协议适配全部由官方 agent 进程负责。
- 使用 Python 3.11+ 的 python3 运行 Superwork 工具；本机 PATH 前置 /opt/homebrew/opt/python@3.14/libexec/bin。
- 不自动提交。并行登记 id=acp-migration-20261109，owner=codex-acp-root-20261109，recordPath=.superwork/parallel/acp-migration-20261109.json。

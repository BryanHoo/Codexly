# Feature Implementation Plan

**Goal:** 发布 `@bryanhu/codexly@1.7.0`，同步全部用户发布文档并完成 npm 与 GitHub Release 发布。

**Suggested Spec Reads:**

- `.superwork/spec/guides/index.md` — 约束版本验证、打包和发布方式。
- `docs/releasing.md` — 定义标签、OIDC、npm 与 GitHub Release 流程。

**Architecture:** 先根据 `v1.6.0..HEAD` 准备版本元数据和双语用户文档，再执行完整质量门禁与 tarball 校验，最后提交、打标签并由 GitHub Actions 发布 npm 包和 GitHub Release。

**Tech Stack:** pnpm、npm、Git、GitHub Actions、GitHub CLI。

## Global Constraints

- 仅发布根包 `@bryanhu/codexly`，内部 Workspace 包保持私有 `0.0.0`。
- 版本标签必须与 `package.json` 完全匹配，且 npm 与 GitHub 不得已存在 `1.7.0`。
- 发布必须使用 `pnpm pack` 生成 tarball，并由现有 GitHub Actions OIDC 流程执行 `npm publish`。
- 提交信息必须使用中文 Conventional Commits，包含必填 scope 和不超过 3 条正文。

### Task 1: 准备 1.7.0 版本文档与元数据

**Files:**

- Modify: `package.json`
- Modify: `CHANGELOG.md`
- Modify: `README.md`
- Modify: `README.zh-CN.md`
- Review: `docs/releasing.md`

**Interfaces:**

- Consumes: `v1.6.0..HEAD` 提交记录与当前产品行为
- Produces: `ReleaseMetadataV1.7.0`

**Behavior:**

- 将项目文件引用、输入历史、统一模型选择、MCP 实时状态、撤销修复、通知去重和端口递增归档到 `1.7.0`，并让双语 README 准确描述当前用户入口。

**Stop Conditions:**

- npm 或 GitHub 已存在 `1.7.0`，或文档描述无法由当前实现与测试佐证时停止。

- [x] **Task Status:** completed

Run: `pnpm exec prettier --check package.json CHANGELOG.md README.md README.zh-CN.md docs/releasing.md`

Expected: 发布元数据与全部相关用户文档格式检查通过。

### Task 2: 验证并打包 1.7.0 发布产物

**Files:**

- Test: `package.json`
- Test: `pnpm-lock.yaml`
- Test: `tools/verify-package.mjs`
- Test: `tests/e2e/**`

**Interfaces:**

- Consumes: `ReleaseMetadataV1.7.0`
- Produces: `VerifiedTarballV1.7.0`

**Behavior:**

- 运行完整检查、端到端测试与本地打包，确认 tarball 可安装且不含 Workspace 协议、源码映射或意外文件。

**Stop Conditions:**

- 任一质量门禁、端到端测试或打包校验失败时停止发布。

- [x] **Task Status:** completed

Run: `pnpm check && pnpm test:e2e && pnpm pack --out /tmp/codexly-1.7.0.tgz`

Expected: 所有检查通过并生成经校验的 `codexly-1.7.0.tgz`。

### Task 3: 提交、标记并发布 1.7.0

**Files:**

- Modify: Git history on `main`
- Create: Git tag `v1.7.0`
- Create: npm package `@bryanhu/codexly@1.7.0`
- Create: GitHub Release `v1.7.0`

**Interfaces:**

- Consumes: `VerifiedTarballV1.7.0`
- Consumes: `.github/workflows/release.yml`
- Produces: 远端 `main`、`v1.7.0` 标签、npm 包和 GitHub Release

**Behavior:**

- 提交已验证的发布准备，创建并推送匹配标签，等待自动发布工作流成功，再核验 npm latest 和 GitHub Release。

**Stop Conditions:**

- 远端分支出现未包含在本地的提交、标签目标不匹配、发布工作流失败或最终注册表状态不一致时停止并保留诊断证据。

- [x] **Task Status:** completed

Run: `gh run watch --exit-status`

Expected: `Release` workflow 成功，npm latest 与 GitHub Release 均为 `1.7.0`。

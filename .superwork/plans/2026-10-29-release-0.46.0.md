# Feature Implementation Plan

**Goal:** 发布 Web/npm 与三平台桌面共用的 0.46.0，并同步中英文用户文档。

**Suggested Spec Reads:**

- `.superwork/spec/guides/index.md` — 全局验证与双端约束。
- `.superwork/spec/root/backend/index.md` — 联合版本与日志契约。
- `.superwork/spec/desktop/backend/index.md` — 桌面原生验证。
- `.superwork/spec/frontend-core/shared/index.md` — 阅读偏好与通知行为。
- `docs/releasing.md` — 发布及失败恢复流程。

**Architecture:** 保持现有发布流水线，以同一不可变提交及标签发布 npm 和桌面产物；仅修改版本元数据及用户文档。

**Tech Stack:** pnpm、Node.js、Cargo、GitHub Actions、Markdown。

## Global Constraints

- 五处版本一致，公开标签不可移动；新增兼容功能提升次版本号。
- 更新日志面向用户，通常 3–6 条；共用能力只写一次，中英文指南同步。
- 不修改历史测试报告、个人配置或其他任务记录。
- 用户已授权发布，执行必要提交和推送；消息使用带 scope 的中文 Conventional Commits。
- 并行登记：`release-0460-20261029`，owner `codex-release-0460`。旧发布登记对应版本已公开，仅维护后续 0.46.0。

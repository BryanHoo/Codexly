# Feature Implementation Plan

**Goal:** 引入 shadcn Skeleton，统一 Web、移动浏览器和桌面端首载占位并保留已有内容与错误反馈。

**Suggested Spec Reads:**

- `.superwork/spec/guides/index.md` — 工程及验证入口
- `.superwork/spec/guides/code-reuse-thinking-guide.md` — 共享 UI 与平台边界
- `.superwork/spec/guides/cross-platform-thinking-guide.md` — 移动与桌面性能
- `.superwork/spec/ui/shared/index.md` — 共享组件契约
- `.superwork/spec/web/frontend/index.md` — Web 与移动端
- `.superwork/spec/desktop/frontend/index.md` — 桌面与 Legacy

**Architecture:** 在共享 UI 中提供 Skeleton 原语和固定数量的语义布局，平台仅注入现有翻译；只替换首次加载和内容懒加载占位。

**Tech Stack:** React、TypeScript、Tailwind CSS、pnpm、Vitest、Chromium / WebKit。

## Global Constraints

- 共享组件不依赖平台代码；不增加请求、定时器、动画运行时或依赖。
- 保留缓存内容、错误重试及真实执行进度；生成中和准备中的任务继续使用既有反馈。
- 复用现有主题与密度，支持 320px 容器、明暗主题及 prefers-reduced-motion。
- 关键实现添加中文注释，桌面文件不超过 500 行。
- 不提交或更改其他任务的登记与代码。

# Feature Implementation Plan

**Goal:** 将 Web、移动浏览器服务与桌面运行时从 Codex 0.164.0 升级适配至最新正式版 0.166.0。

**Suggested Spec Reads:**

- `.superwork/spec/guides/index.md` — 全局验证与跨端约束。
- `.superwork/spec/provider-codex/backend/index.md` — 进程、RPC、分页与图片边界。
- `.superwork/spec/desktop/backend/index.md` — Rust 与跨平台验证。
- `.superwork/spec/root/backend/index.md` — 依赖、构建和包体门禁。

**Architecture:** 继续使用 stdio App Server；两端在 Provider 边界将新条目时间戳映射至既有 itemTimings，保持分页外层旧数据兼容；共享 Schema、依赖版本和测试样本。

**Tech Stack:** TypeScript、Rust、pnpm、Vitest、Cargo。

## Global Constraints

- 不增加轮询、全量历史传输、逐模型探测或新运行时依赖；保留 JSONL 背压、有界队列和懒加载。
- 两端共用根依赖、Schema 和跨语言契约样本；关键执行边界添加中文注释。
- 使用 Python 3.11+ 的 python3；沿用 pnpm@11.22.0。
- 只读取本地官方源码 tag，不切换上游工作区；源码路径来自 Git 忽略配置。
- 旧公告的发布策略已通过 51b42733 合入，当前版本为 0.47.1；冷启动预算已经合入 process.rs，保留 15 秒，不清理他人公告。

# Feature Implementation Plan

**Goal:** 发布 Codexly 0.43.0，统一 Web/npm 与桌面版本，同步中英文用户文档并验证联合发行物。

**Suggested Spec Reads:**

- `.superwork/spec/guides/index.md` — 工作区、跨平台和验证入口。
- `.superwork/spec/root/backend/index.md` — 联合版本、更新日志和发布校验契约。
- `.superwork/spec/protocol/shared/index.md` — 整合诊断 ZIP 与归档日期清理语义。
- `.superwork/spec/frontend-core/shared/index.md` — 完整对话 JSON 导出的能力边界。
- `docs/releasing.md` — 必需本地门禁、不可变标签和发布完成条件。

**Architecture:** 沿用根目录更新日志和现有 GitHub Actions 联合发布流程，只修改版本元数据与用户文档。

**Tech Stack:** pnpm 11.22.0、Node.js 24、Rust/Tauri、Markdown、GitHub Actions。

## Global Constraints

- Web/npm、桌面 package、Tauri、Cargo 和 Cargo lock 必须统一为 0.43.0。
- 新增兼容功能提升次版本号；保留历史日志与报告事实，不移动已推送标签。
- 同时考虑桌面 macOS / Windows / Ubuntu、电脑 Web 与移动浏览器；共享功能只记录一次。
- 发布正文只提取根日志对应版本，保留桌面更新隐藏标记；所有门禁通过后才公开联合 Release。
- 使用 pnpm 和 Python3，不提交本机路径、凭据或诊断日志。
- 本次仅修改元数据与文档，复用现有校验，不添加重复实现的测试。
- 用户已授权发布；使用 `chore(release): 发布 0.43.0 并同步使用文档` 提交，推送 main 与注释标签。
- 并行登记：id `release-0430-20261026`，owner `codex-release-0430`，recordPath `.superwork/parallel/release-0430-20261026.json`。

# Feature Implementation Plan

**Goal:** 将 Web 与桌面共享的 Agent 连接全部切换至 ACP v2。

**Suggested Spec Reads:**

- `.superwork/spec/core/shared/index.md` 涵盖 ACP 的会话、历史和持久化约束。
- `.superwork/spec/protocol/shared/index.md` 定义双端回合和停止原因。
- `.superwork/spec/guides/index.md` 定义工程与验证约束。

**Architecture:** 共享连接使用官方 v2 SDK。完成信号、会话回放和事件进入现有共享存储与投影。

**Tech Stack:** TypeScript、ACP SDK、pnpm、Vitest。

## Global Constraints

- Web 与桌面复用 ACP 运行时，流式增量和背压保留。
- 历史提交成功后才发布持久回合完成并续发队列。

## 验证结果

- ACP 连接测试验证拒绝旧协议、写入回执与前台终态的边界，以及历史重放完成标记。
- 根目录 `pnpm test` 通过 4580 项。根目录类型、构建、格式、静态检查、依赖边界、包体和发布包校验均通过。
- macOS 真实 Codex 和 Claude adapter 安装握手通过。编译桌面宿主的 12 项检查和桌面 ACP 认证、设置页面的 46 项浏览器测试通过。
- Web ACP 认证的 6 项浏览器测试通过。首次引导和启用 Agent 的额外回归在迁移前的工作树也可复现失败。
- 扩展桌面浏览器测试通过 286 项，另有设置页面、默认值和思考流测试失败。迁移前的 Chromium 基线已复现这些测试组的代表性失败。Windows 和 Ubuntu 的官方安装产物由对应平台的发布测试验证，本次在 macOS 实机运行。

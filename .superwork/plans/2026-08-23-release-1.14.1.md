# Feature Implementation Plan

**Goal:** 发布 CodeAgent 1.14.1，修复 SQLite 原生模块崩溃和 Worker 强制终止问题，并将最低 Node.js 版本确定为 22.14.0。

**Suggested Spec Reads:**

- `.superwork/spec/guides/index.md` — 定义版本、发布包和质量门禁约束。
- `.superwork/spec/backend/runtime-lifecycle.md` — 定义数据库 Worker 的关闭与原生运行时兼容规则。
- `.superwork/spec/shared/quality-guidelines.md` — 定义 Release 的最低 Node.js 版本和测试隔离规则。

**Architecture:** 将 `better-sqlite3` 固定到兼容 Node.js 22.13.0 的版本，数据库 Worker 在关闭响应后等待自然退出并仅在超时时强制终止；补丁版本通过现有 tag 驱动工作流发布。

**Tech Stack:** TypeScript、Node.js Worker Threads、Vitest、pnpm、GitHub Actions、npm

## Global Constraints

- 使用 `pnpm` 执行项目命令，使用 `python3` 执行 Python 命令。
- 发布版本、annotated tag 与 npm 版本必须统一为 `1.14.1`。
- 发布前必须在 Node.js 22.14.0 下通过完整 `pnpm check`。
- 提交信息必须符合中文 Conventional Commits 格式。

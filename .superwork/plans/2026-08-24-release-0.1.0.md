# Feature Implementation Plan

**Goal:** 通过 GitHub Actions 发布 `@bryanhu/codexly@0.1.0`，完成 npm 包初始化、更新日志与 GitHub Release。

**Suggested Spec Reads:**

- `.superwork/spec/guides/index.md` — 定义根包名称、发布包和质量门禁约束。
- `.superwork/spec/shared/quality-guidelines.md` — 定义 Release 运行时与测试隔离规则。
- `docs/releasing.md` — 定义首次发布、Trusted Publisher、标签和失败恢复流程。

**Architecture:** 复用现有 tag 驱动的 `release.yml`；首次创建 npm 包时由 GitHub Actions 使用临时 granular access token，发布成功后绑定 Trusted Publisher 并删除临时 token，后续版本只使用 OIDC。

**Tech Stack:** pnpm、npm、Git、GitHub Actions、GitHub CLI

## Global Constraints

- 仅发布根包 `@bryanhu/codexly`，内部 Workspace 包保持私有。
- `package.json`、annotated tag、npm 版本与 GitHub Release 必须统一为 `0.1.0`。
- 发布对象必须由 `pnpm pack` 生成，再由 npm CLI 发布。
- 提交信息必须使用中文 Conventional Commits，并包含必填 scope。

### Task 2: 配置 GitHub Actions 首发凭据

**Files:**

**Behavior:**

**Stop Conditions:**

- `NPM_TOKEN` 尚未配置、不能绕过发布 2FA 或没有 `@bryanhu` scope 写权限时停止。

- [x] **Task Status:** completed

Run: `pnpm exec vitest run tests/ci-quality-gates.test.ts`

Expected: Release workflow 保留 `pnpm pack`，并能将 `NPM_TOKEN` 只传给 npm 发布步骤。

Expected: Release workflow 成功完成。

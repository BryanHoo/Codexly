# ACP v2 聊天体验

## Goal

在 Web 和桌面聊天中呈现 ACP v2 发送确认、会话恢复、后台任务和结构化文件变更。

## Suggested Spec Reads

- .superwork/spec/core/shared/index.md
- .superwork/spec/protocol/shared/index.md
- .superwork/spec/ui/shared/index.md

现有共享运行时已有回合结束信号、回放完成标记和提交幂等键。回执还需传给界面，回放与实时事件需按协议标记分流。

可以扩展单个回合，也可以扩展现有会话状态。采用会话状态承载发送确认、前台状态和后台清单，因为后台工作可以超出单个回合。历史文件变更沿用聊天条目，在回放及实时处理共用相同映射。停止请求由当前会话及实体能力授权。回放失败保留本地历史，状态不明时保留重复提交保护。

验证覆盖回执先于终态、回放边界、后台工作结束后更新、取消能力校验及无文本补丁的文件操作。双端共用状态组件，HTTP 与桌面宿主各自验证参数和会话归属。

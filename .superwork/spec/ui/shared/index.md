# 共享 UI

- 两端异步任务启动响应始终更新原任务缓存与运行状态，但选中任务和导航必须受 `core/use-current-view` 的视图身份约束。切换、卸载或离开后返回同一路由，都不能让旧请求抢回当前页面；通过 Chrome CDP 验证新任务发送后立即切走、响应返回后页面不变且任务在后台继续运行。

- 语言支持以 `agent/code-languages.ts` 为准。Web、桌面及 Legacy 构建共用 `tools/project-language-plugin.mjs`，在打包前裁剪依赖语言映射和 Markdown/MDX 未注册的内嵌规则，避免第三方完整语言表恢复已移除的支持；普通围栏保留纯文本回退。根目录 `pnpm test:highlight` 覆盖映射、规则引用与正则保留，联合发布必须执行。

`@codexly/ui` 存放 Web 与桌面端视觉和交互一致的 React 控件。各端现有组件路径可用薄导出维持调用点，但组件实现只保留在 `packages/ui/src/`。

- 左栏添加项目按钮左侧提供时间线／项目分组切换，偏好单独持久化，不改写项目或临时任务的展开状态。时间线共用 `core/sidebar-task-timeline`，面板与分组计算按需加载，归档管理代码也只在打开时加载；平台只适配完整目录查询、翻译和原任务行；继续复用审批、运行、未查看完成、失败标记、分屏选择及任务操作。时间组标题使用醒目字重、底色和展开箭头，数量固定在行最右侧；标题在所属分组内原生吸顶，到组尾由下一组接替。虚拟列表按组保留有明确高度且不带 transform 的容器和不透明标题，仅任务行参与视口裁剪；键盘定位为吸顶标题预留顶部空间，不能遮住聚焦任务；各组独立保存折叠偏好，“更早”默认折叠。仅启用时间线时读取所有项目与临时任务的近期元数据分页，到一周前边界即停止，不能依赖已展开项目的分页或读取聊天正文。只有展开“更早”才启用 `search-source` 完整目录，收起即停止历史刷新；短期再次展开复用缓存。历史总数尚未知时显示省略号，不能为提前统计数量加载全部历史。近期结果使用 `timeline-recent` 独立查询键，写操作、标题通知及窗口恢复均需同步校准。新建、启动、重命名、固定、归档及回合终态通过共享 `sidebar-task-catalog-cache` 同步目录，旧请求不能覆盖操作结果；目录尚未加载时不得写入局部集合，取消后必须重新启动活动读取。长列表仅挂载可见行，保留焦点行及键盘首尾导航；跨午夜重分组只用一次性日界定时器，后台暂停，恢复可见时校准。部分目录失败保留成功结果并提供重试，Web 移动导航后关闭侧栏。回归使用 `sidebar-task-timeline.test.ts`、桌面 `project-timeline-cache.test.ts`、`sidebar-task-timeline.browser.test.tsx` 与 `app-shell-sidebar-timeline.spec.ts`，覆盖时间边界、完整目录、竞态、2,000 条任务虚拟化及跨浏览器切换。

- 任务上下文的 MCP 列表共用 `core/mcp-server-panel`，Claude 与 Codex 使用相同的服务行和标题栏刷新入口；重连、重载配置按需放入更多菜单，未提供快照语义的旧引擎保留默认操作调用。底部不展示缓存状态或观测时间。默认最多挂载五行，支持展开与收起；两端回归需覆盖状态、空快照、只读和忙碌状态，并通过 Chrome CDP 检查窄屏、主题与菜单操作。

- 左栏固定与运行中共用 `core/sidebar-task-shortcuts`，每组默认预览两条、合计最多 240px 且不超过任务导航区高度的三分之一；极小窗口保留标题计数入口。自动限高不能改写手动折叠偏好，完整列表由宽屏浮层或 Web 移动抽屉承载，不挤压项目树；大列表仅挂载可见虚拟行。未查看完成任务优先，其后依次为待确认、运行任务；分组计数显示全部成员总数，额外标示待确认数量，活动成员独立于历史分页；同类任务排序不能随流式正文重排。运行入口遵守已有分屏选择规则，后台完成且未查看的任务保留在分组并显示完成图标，计入分组总数；聚焦该任务后由现有 attention 清除流程移出分组，不关闭会话，聚焦其他任务不能消费提醒。移动端浮层导航（包括重复选择）须通过平台回调收起原侧栏，关闭浮层不能夺回任务焦点。回归见 `frontend-core/sidebar-task-shortcuts.test.ts`、Web 的 `sidebar-task-shortcuts.test.tsx`、`project-sidebar-task-list.test.tsx`、`project-runtime-events.test.ts` 与桌面 `project-runtime-restore.test.ts`；通过 Chrome CDP 检查宽窄屏、矮窗口、折叠恢复及完整列表导航。

- 工具耗时共用 `@codexly/ui/agent/tool-duration`：保留 100ms 刷新与现有显示精度，每个页面仅运行一个共享时钟和一个视口观察器；仅运行且处于视口内的工具参与更新，文档隐藏立即暂停，恢复可见按绝对时间校准，完成后使用服务端终态时间并退订。最后一个活动工具卸载或完成后释放定时器、观察器及可见性监听；旧 WebView 无观察器时保留文档可见性控制。回归见 `packages/ui/src/agent/tool-duration-clock.test.ts` 及两端时间线耗时测试。

- 会话重连提示共用 `core/reconnecting-notice`：连续恢复连接不足 10 秒时静默，超过窗口后才显示状态，连接恢复立即隐藏；再次断连或切换任务重新计时，卸载释放一次性定时器。主会话和子代理窗口只保留时间线内的一处提示；展示延迟不能改变真实连接状态或提前开放写入操作。回归见 Web 的 `task-timeline-basics.test.tsx`，通过 Chrome CDP 验证短暂失败、持续失败、恢复及切换任务。

- 基础控件从 `@codexly/ui/core/*` 导入；Agent 展示组件只在平台行为拆出后从 `@codexly/ui/agent/*` 导入。
- Tooltip 不因获得或恢复焦点自动打开；共享 Trigger 保留业务焦点回调，仅阻止 Radix 的焦点打开行为，鼠标悬停仍展示。承载正文的自定义备注提示需支持点击及键盘主动查看。
- Composer 权限与沙盒使用共享 `CompactSelector` 锚定下拉菜单；触发器与模型、思考量保持一致，支持窄屏标签截断和视口碰撞边界，不使用原生 select 弹层。
- Composer 附件按钮固定在工具栏最左侧，引擎与其他操作放在其后。Codex 与 Claude 均已配置时才显示引擎选择器；仅配置一种时新草稿自动使用该引擎，忽略失效的草稿选择。已有会话保留原引擎；配置发现完成前禁止提交新草稿，旧版 macOS 不探测 Claude。两端共用 `engine-composer` 与 `engine-composer-state`，回归覆盖单配置、双配置、配置移除与历史归属。
- 文件打开、下载、Markdown 链接、通知和翻译由调用方提供。公共包不引入 Tauri API、Web 客户端或应用内 feature 代码。
- Codex 的 `:codex-file-citation{path="..."}` 在静态消息和流式回复中共用文件卡片，点击通过平台回调交给宿主的系统默认应用；Web 的宿主是服务端所在机器。路径按文件系统字面值保存，兼容 Windows 盘符、UNC、中文、空格及 Markdown 特殊字符；不对代码示例和已有链接里的引用执行转换。只处理当前 Markdown 块，文件内容不因渲染卡片而读取或传输。回归见两端 `message-response-file-citations.test.ts` 与共享 `codex-file-citation.test.ts`、`message-file-citation.test.ts`。
- Assistant Directive 语法在共享层解析：接受一至三个冒号、带嵌套方括号和行内代码的建议标签、单双引号、属性两侧空格及引号转义；拒绝重复属性。文件路径和隐藏 prompt 按字面内容保存，Markdown 粗体修复不能改写属性。代码、已有链接、原始 HTML 及未知指令的隐藏属性内不执行嵌套转换，流式未完成语法保留可读预览。解析候选共用有界扫描预算，禁止反复扫描完整历史正文。
- `:codex-followup[label]{prompt="..."}` 显示后续建议；仅任务自己的工作台提供点选回调，追加到最新草稿并唤起所属分屏输入框，保留 Skill、文件引用和附件，实际发送由用户触发。只读任务和独立任务小窗保留标签。建议标签中的链接保留文字与排版，避免按钮嵌套另一个导航控件。
- `::git-stage`、`::git-commit`、`::git-create-branch`、`::git-push`、`::git-create-pr` 显示操作回执与分支信息；PR 区分草稿，仅 HTTP(S) URL 提供网页入口，桌面复用系统浏览器导航。回执渲染不触发 Git 操作。`::codex-inline-vis{file="..."}` 和 `visualize{"path":"..."}` 提供可视化文件的系统打开入口；`::codex-realtime-inline{}` 作为呈现标记隐藏，后续正文保留。回归见两端 `message-response-directives.test.ts`，共享 `assistant-directives.test.ts`、`followup-draft.test.ts` 与 `message-assistant-directive.test.ts`。
- `code-comment` 共用官方属性语法，保留同一行的后续回执，校准评论行号范围和 P0–P3 优先级；围栏代码示例不能被抽取成真实评论。原生 Codex 已移除记忆引用内部标记，并将计划模式的 `proposed_plan` 交由计划事件呈现，前端继续沿用既有事件处理。
- 新建项目表单共用 `core/new-project-dialog.tsx`，父目录选择切换同一模态层并保留名称；目录创建与项目注册分开，注册失败只重试添加，同名目录须明确确认复用。Web 的文件系统操作面向服务器，须展示主机信息并验证移动端布局。
- 两端 `globals.css` 从应用 `src` 扫描 Tailwind 类，保留 `packages/ui/src` 与第三方组件的显式扫描，并排除测试文件；不得仅扫描 `.tsx`，排版类也可能定义在 `.ts` 中。
- Web 对外可读取的 `--color-brand` 与 `--color-control-hover` 通过 `@theme inline static` 保留，不能依赖测试源码使变量进入生产 CSS；用主题 E2E 校验浅色和深色的实际解析值。
- 消息附件、项目图片和壁纸原图共用 `core/image-preview`，翻译由各端传入；手势引擎仅在预览挂载时加载。预览支持容器内缩放、拖动、双指手势和复位，切换资源或容器尺寸变化时恢复适配；捏合后的触摸拖动不得误判为双击。用 `desktop/src/shared/components/core/image-preview.browser.test.tsx` 验证 Chromium、WebKit 和移动端窄屏。
- 聊天 Markdown 的本地图片共用 `core/message-markdown-image`；文件链接规范化产生的相对路径、Windows 盘符及 UNC 标记须先还原，再通过任务所属工作目录的图片接口读取，禁止将本地路径直接作为网页地址。Web 使用受控文件 URL，桌面复用原生缓存与 asset 通道；普通任务未绑定 `workspacePath` 时使用所属项目的根选择，worktree 绑定目录始终优先；历史回放与分屏不能借用其他活动项目目录，任务切换后丢弃旧异步结果。图片不以 Base64 消息正文传输。正文图片本身可点击打开各端已有预览弹窗，不另加可见按钮；共享层仅在地址解析后注入预览包装，弹窗复用已解析地址并按需加载，不重复读取原生文件。触发区使用自适应宽高，流式追加及终态切换保持已打开的弹窗。回归见两端 `message-response-images.test` 与共享 `markdown-image-source.test.ts`。
- 流式 Markdown 的树形渲染与文本揭示动画放在 `agent/streaming-markdown`，两端引入其共享样式；稳定前缀不能因追加或动画结束而重挂，正文 key 与动画状态无关，纯文本快路径不随结束状态切换。大尾块由共享单 Worker 队列解析，等待期间保留预览，正文变更或卸载时取消旧任务，闲置后释放线程；Worker 失败保留可读预览，禁止退回主线程同步解析超大内容。图表和自定义插件不得被普通代码快路径替代。
- 主线程与 Markdown Worker 共用 `agent/markdown-block-lexer`；只导入 marked 等无 DOM 的解析依赖，不从 Streamdown 渲染入口导入 lexer。升级 marked / Streamdown 时运行共享 lexer 的逐边界对照测试，并检查两端 Worker 构建产物可在无 DOM 环境执行。
- 验证边界使用 `apps/web/src/shared/components/shared-ui-boundary.test.ts`、根目录 `pnpm lint:architecture`，并分别运行 Web 与桌面构建。
- 只读代码查看器共用 `agent/code-block-content`、`code-block-pages` 和 `code-highlighter`。正文按行虚拟化，完整源码（含所有分页）超过 128 KiB UTF-8 时跳过语法高亮；限额内按批次让出浏览器任务队列并传递双主题语法状态，超长行保留纯文本。目标行定位由虚拟列表处理，只有行尚未加载时才补页，不得根据离屏 DOM 缺失读取剩余全文。回归覆盖一万行的节点与标记预算、UTF-8 与分页总预算、跨批次注释/字符串及交互任务执行；桌面旧 WebKit 主题兼容保留。
- 代码查看器的组合组件、按需高亮与字节缓存统一由 `agent/code-block`、`code-tokenizer`、`code-token-cache` 实现；Web 与桌面包装层只注入翻译和旧 WebKit 主题参数。复制时才拼接分页全文，普通渲染不生成额外完整源码副本。两端本地 LRU、快照预算与高亮缓存路径保留薄导出，由 `shared-ui-boundary.test.ts` 防止重新引入独立实现。
- Web 与桌面的 Inspector 文件预览面板只在打开源码、图片或 PDF 时加载，不进入工作台的静态依赖闭包；以两端生产构建和桌面场景体积预算验证。源码分页 E2E 必须滚动实际视口触发补页，不能定位尚未挂载的虚拟行，并检查补页后的节点数量仍受限。

- PDF 文件链接、附件和文件树共用 `core/pdf-preview` 原生预览；用 `navigator.pdfViewerEnabled` 检测能力，缺失时保留显式打开动作。附件点击后才加载，关闭后卸载；不引入 PDF.js 或 Base64 整文件传输。桌面只开放校验后的单文件 asset scope，独立预览窗口同时授权读取和打开命令。

- 分屏输入区域共用 `core/split-composer`，新建任务的草稿窗口默认展开，已有任务默认收起，各窗口可独立手动切换；恢复单窗口或移动端时自动展示。分支、项目路径和上下文底栏始终可见，展开/收起按钮放在该底栏。保留编辑器 DOM、草稿、附件和队列，隐藏区不可聚焦；待回答问题及可用的停止入口不得被收起遮挡。文件引用、底栏草稿恢复应唤起输入框；无底栏的定时任务编辑器不参与收起。
- 分屏输入框收起时，底栏通过共享 `core/composer-model-status` 显示当前解析后的模型与思考量，只提供文本，不提供配置操作；剩余宽度不足时整组隐藏，空间恢复后重新显示。展开输入框或回到单窗口时移除摘要，验证长模型名、窄栏、拉宽恢复及草稿保留。

- 左右栏属于工作区外层，只有中栏参与分屏。右栏共用 `core/split-inspector` 的开关及挂载位置，活动窗口通过 [React Portal](https://react.dev/reference/react-dom/createPortal) 提供右栏内容并保留其任务回调；不得为右栏另建任务订阅。非活动窗口停用右栏专属查询，分屏切换时保留各自文档/标签及全局面板宽度。左栏高亮和 `aria-current` 以活动窗口身份为准，不能让未改变的 URL 再激活原任务。
- 外层工作台各栏必须按语义固定网格列和行，不能依赖 Portal 与中栏的 DOM 插入顺序；扩展中心返回任务后仍保持左栏、中栏、右栏的位置。嵌入聊天及窄屏中栏使用唯一显式列，避免产生隐式列。使用 `desktop/src/shared/components/core/workbench-panel-order.browser.test.tsx` 验证两端样式、连续切换、侧栏开关与宽窄窗口。
- 用户消息快捷目录通过 `core/timeline-navigation-host` 定位到所属窗口，采用窗口内绝对定位及相对高度；禁止使用全局首个 `.workbench-shell` 或视口固定定位。回归检查四屏目录互不重叠、右栏切换内容、侧栏唯一激活项、收起状态及草稿保留。
- 分屏时左栏普通任务点击由工作区接管：目标未打开则原位替换聚焦窗口，已打开则只切换焦点，禁止退出分屏或删除原窗口；其余窗口的顺序、草稿和挂载身份保持稳定。单窗口、移动端及修饰键打开链接继续使用原有导航行为。回归覆盖四屏满额替换、重复选择及跨项目任务身份。
- Web 通知与桌面原生任务跳转沿用分屏任务选择规则，按点击时的最新焦点处理，禁止通过路由切换重置分屏。工作区未挂载、单窗口及移动端回退到平台路由；卸载工作区必须清理导航监听。回归覆盖项目与临时聊天通知、四屏布局及相邻草稿保留、已打开任务聚焦和导航回退。

- Claude 扩展仅在进入对应栏目时查询，缓存按引擎、分类和项目隔离；短期重复进入应复用缓存与在途请求，不因窗口聚焦重读目录。刷新显式重读，写入后更新当前范围并使相关扩展缓存失效；插件可能提供 Skills 和 MCP，失效项在下次进入时读取。大目录使用共享 `core/extension-list` 虚拟列表，支持可变行高和移动端尺寸，挂载数量随视口变化，不能一次初始化全部 Tooltip、开关。
- Codex 与 Claude 共用右上角范围选择。Codex Skills 从发现结果按 `scope` 与 `projectId` 过滤；MCP 按登记项目解析 cwd，使用官方 `config/read` 的项目层区分自有服务与继承服务。官方写入接口只允许用户配置，因此项目 MCP 只读并说明原因，不得借项目开关写入全局配置。回归包括 `extension-center.test.tsx`、两端 Skills/MCP 客户端、Codex provider 与原生 catalogs 测试，以及 Chrome CDP 缓存、虚拟滚动和项目隔离验证。

- Claude 扩展操作按插件 ID 与当前分类、项目记录进行中状态，安装仅禁用对应插件并显示转圈及 `aria-busy`；其他插件、搜索、筛选和刷新继续可用。同一插件重复点击不得重复请求，多个插件同时进行时，各自完成或失败才释放自己的状态。完整目录响应只合并本次操作的插件，防止乱序响应覆盖其他已确认结果；同步目录也需保留同步期间完成的变更。使用 `claude-plugin-pending.test.tsx`、`frontend-core/claude-extension-cache.test.ts` 及 Chrome CDP 验证并行安装、失败恢复和重复点击。

- Codex、Claude 的 Skills、MCP、官方插件必须复用 `core/extension-catalog` 的工具栏、列表行、开关和移除确认，以及 `core/extension-list` 的虚拟列表；禁止恢复引擎专用卡片墙或按安装状态分栏。搜索、筛选、范围徽标、图标操作和禁用原因的视觉与键盘交互保持一致；具体能力由原生接口决定，不能为 Codex 增加无官方接口支撑的插件启停或更新按钮。
- Codex 的平台面板仅适配客户端与翻译；资源列表和插件状态由共享面板管理。插件直接行内安装并逐项显示 loading，点击名称才延迟读取详情；需要授权时显示该插件的授权入口，详情内捆绑 Skills/MCP 只读。移除统一确认，独立插件操作可同时进行；目录同步不可覆盖期间已确认的安装结果。回归包含 `official-plugin-catalog.test.tsx`、`plugin-reconcile.test.ts`、Tooltip Slot 合约，以及 Chrome CDP 的两种引擎、三个栏目、宽窄屏、安装授权和项目隔离。

- 常用提示词使用两端共用的 `core/saved-prompts-settings` 管理界面与本机版本化存储，不依赖引擎连接；快捷词支持中文，同一范围内忽略大小写查重。默认全局，可绑定单一项目；聊天候选仅包含全局及当前项目，同快捷词优先使用项目版本。管理页提供全部、全局及指定项目筛选，并展示所属范围；切换范围纳入未保存草稿保护。项目列表不可用时不能将原项目范围误存为全局。删除项目的确认文案须说明本机绑定提示词将全部删除，预检存储写权限，远端成功后按项目清理，远端失败保留提示词。先落盘再发布新列表，失败保留草稿，删除与放弃编辑须确认。斜杠菜单默认和搜索都最多展示 12 项；默认兼顾常用提示词、内置命令、Skills，搜索按精确、前缀、包含匹配选出全量索引中的最佳少量结果，匹配索引跨分屏复用、按项目缓存并限制缓存数量；禁止全量渲染、全量排序或逐键读取存储、扫描提示词正文。分组后的键盘索引必须与视觉顺序一致。选择只替换光标前的快捷词，保留前后文字、引用与附件，同步定位光标，不自动发送。回归见 `saved-prompts.test.ts`、`prompt-suggestions.test.ts`、Web `saved-prompt-command.test.ts` 及桌面 `saved-prompts.browser.test.tsx`、`composer-ownership.browser.test.tsx`。

# 模型与思考强度

桌面、电脑 Web 与移动浏览器使用同一套 ACP 设置和会话配置。模型来自 Agent 公布的 `model` 类别，思考强度来自当前配置中的 `thought_level` 类别。选择器保留 Agent 提供的标识、名称、顺序与当前值。

新聊天使用所选 Agent 的配置和应用保存的默认选项。续聊使用原会话确认的配置。切换模型后，应用读取 Agent 更新的选项，思考强度菜单随该选项的存在与值变化。

认证和模型目录由 Agent 管理。Agent 公布 ACP 供应商配置能力时，可通过「设置 → ACP」调整供应商。设置界面显示该 Agent 当前确认可用的模型。详见 [ACP Agent](agent-engines.md)。

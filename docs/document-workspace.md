# 聊天与文件工作区设计

本方案面向在 AI 对话、项目文件与代码变更之间反复核对的用户。文件内容进入中栏，导航列表保留原位，避免每打开一个文件就丢失文件树或变更列表。

## 布局与选择依据

| 区域 | 职责                                            | 打开内容后的行为                     |
| ---- | ----------------------------------------------- | ------------------------------------ |
| 左栏 | 项目、任务与搜索入口                            | 保留任务导航，文件交给聚焦任务       |
| 中栏 | 聊天、源码、图片、PDF、Diff、批量审核、提交详情 | 使用独立、可关闭的文档标签；聊天常驻 |
| 右栏 | 项目文件树、变更列表、提交历史、运行上下文      | 点击条目后保留原来的导航标签与列表   |

采用中央内容标签而非继续扩充右栏，是因为文件与差异需要主要阅读空间；文件树和变更列表需要在阅读时持续可用。聊天仍是默认入口，纯聊天用户无需选择文件或调整布局。

视觉沿用项目语义色：内容白色 `#ffffff` / 深色 `#181818`、主强调蓝 `#006aff` / `#339cff`，边界使用已有低对比度分隔线。标签采用现有系统字体，源码沿用等宽字体；不引入新字体下载、动画库或工作台框架。选中标签使用与右栏一致的低对比度灰色底，无强调下划线；桌面标签栏高 28px，仅有聊天时隐藏整个标签栏；打开文件或变更后显示。标签栏显示时，聊天标签始终位于首位，不可关闭、取消固定或拖移，横向滚动时仍保持可见。文件类型图标区分源码、图片和变更，完整路径通过悬停查看。

## 实际操作

1. 点击文件树、搜索结果或消息中的文件引用，内容在当前任务的中栏标签打开。
2. 点击「聊天」返回会话，草稿和聊天 DOM 状态保留。
3. 在文件标签工具栏选择「与聊天左右对照」或「与聊天上下对照」，同时阅读聊天和文件。拖动分割线调整比例，方向键微调，双击恢复等分。
4. 再次点击已选中的对照按钮恢复单栏；点击常驻「聊天」标签返回聊天并退出对照，保留文件标签。右侧保留带 Tooltip 的左右对照、上下对照按钮及「标签操作」菜单。回到聊天时对照按钮暂时置灰。关闭当前文件优先选择右侧存活标签，否则选择左侧；最后一个关闭后返回聊天并隐藏标签栏。
5. 文件、变更等文档标签可拖动排序；插入线显示落点，靠近边缘自动滚动，取消拖动保留原顺序。固定标签排列在普通标签之前，拖动不会隐式改变固定状态；固定和普通标签分别在各自分组内排序。
6. 右键标签或按 Shift+F10 打开菜单，提供固定、取消固定、左右移动、关闭、关闭其他、关闭左侧、关闭右侧、关闭所有、关闭未固定、关闭固定及对照操作。右键后台标签不会切换当前文档。常规批量关闭保留固定项；「关闭」可以显式关闭单个固定项，「关闭固定标签」可以关闭固定文件。所有操作均排除聊天。
7. 固定标签的关闭按钮替换为图钉，点击取消固定；Delete 和鼠标中键不关闭固定项，避免误操作。普通标签继续支持 Delete 和中键关闭。左右方向键、Home、End 切换标签，Alt+Shift+左右方向键在同组内移动当前标签；保存失败时保留原选择和焦点。
8. 标签过多时可用鼠标滚轮、触控板横滑或触摸滑动浏览。当前文件在聊天右侧可用区域内居中显示完整标签（包含关闭按钮），排序及栏宽改变后重新定位；聊天始终可见。

现有任务分屏仍支持最多四个任务。每个任务有自己的标签和对照状态，右栏跟随当前聚焦任务。从侧栏、搜索或通知导航到任务时自动回到聊天，保留已打开的文件标签；普通点击分屏内的文件区域只切换焦点，不重置文档。任务分屏与聊天/文件对照是两种不同操作：前者处理多个任务，后者核对一个任务的内容。当前不提供文件标签跨任务拖移、任意文件对文件分组或重启后的标签恢复。

手机及触摸设备保持单组标签，打开文件自动收起覆盖内容的侧栏；不展示对照入口。右侧「标签操作」菜单支持固定、取消固定、左右移动与批量关闭，保留原生触摸横向滚动。桌面缩小再恢复时，对照方向仍保留。

## 状态、安全与性能边界

- 两端共用文档状态、标签、对照布局、快捷键和分割线，只保留客户端与文件查看器的宿主适配。
- 纯聊天隐藏整个标签栏；首次打开文档时按需加载增强标签栏，加载期间仍可返回聊天。菜单和拖动代码不进入纯聊天的静态加载闭包。
- 标签只保存资源描述。只有当前文档挂载查看器，后台标签不挂载图片、PDF、代码高亮或 Diff。
- 聊天使用 React `Activity` 保留状态，隐藏时暂停界面副作用；任务运行时位于边界外，继续接收事件。
- 文本复用已有带容量预算的编辑会话缓存、撤销和滚动快照。切换与关闭等待保存；保存失败保留文件和草稿。迟到的保存不能恢复已离开的工作目录。
- 文件树、搜索与消息的路径按项目和根目录统一身份，重复打开复用标签；不同工作树相同相对路径隔离。
- 标签拖动期间只更新 DOM 插入线和必要的边缘滚动，放下时才提交顺序；不逐帧刷新 React，不增加拖动依赖。拖出、取消或卸载时释放帧任务。
- 批量关闭使用单次保存保护，失败时整批保留；后续导航、切根或卸载会使旧保存请求失效。排序和固定不触发保存，也不重新挂载当前文档。
- 对照分割线拖动只写布局 CSS 变量，释放指针后才更新语义状态，不逐帧刷新聊天和编辑器。
- 当前标签与布局只在本窗口生命周期内保留；不将文件内容复制到布局状态或持久存储。

## 官方参考

- [VS Code：用户界面、标签与编辑器组](https://code.visualstudio.com/docs/getstarted/userinterface)：导航与主要内容分区，活动编辑器接收新文件，支持并排阅读。
- [JetBrains：Editor basics](https://www.jetbrains.com/help/idea/using-code-editor.html)：文档标签、预览标签、拆分和键盘切换。本实现使用显式文档标签，避免连续浏览时替换用户正在编辑的内容。
- [React：Activity](https://react.dev/reference/react/Activity)：保留隐藏界面状态并清理其副作用。

## 验证入口

共享状态与资源身份见 `packages/frontend-core/src/document-*.test.ts`。真实 Chromium / WebKit 的草稿、保存保护和挂载数量验证见 `desktop/src/shared/components/core/document-workspace.browser.test.tsx`。完整 Web、移动与多任务分屏流程见 `tests/e2e/app-shell-document-workspace.spec.ts`。

这些验证检查资源生命周期、布局与行为，不代表真实大型项目、所有操作系统上的帧率或内存峰值基准。

分屏快捷键在 Web 和桌面端统一为 `Alt + Shift + 方向键`（macOS 的 Alt 为 Option），方向键决定新窗格的位置。旧的 `Cmd/Ctrl + Alt + 方向键` 保留给浏览器；可在左下角“帮助 → 键盘快捷键”查看当前平台支持的操作。

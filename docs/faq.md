# 常见问题

[文档导航](README.md) · [首次使用](getting-started.md) · [Web 与移动端](web.md)

## 桌面、Web、移动端是什么关系？

桌面版是 macOS、Windows 和 Ubuntu 上的独立应用，内置运行时；Web 版通过 npm 启动本地服务。移动端是 Web 的小屏浏览器界面，不是独立安装包。桌面应用不自动开启局域网服务，需要手机访问时另行启动 `codexly start --lan`。

## 只使用 Claude 可以吗？

可以。聊天、项目、公共设置、Git 提交说明生成与定时任务不要求配置或启动 Codex。macOS Legacy 安装包除外，该版本只支持 Codex。已创建任务的引擎固定，要换引擎请新建任务。

## Claude 怎么登录？

应用不提供 Claude 账号登录。可复用主机上受支持的 Claude Code 认证，或填写支持 Anthropic Messages API 与 `/v1/models` 的服务地址和密钥。连接检测成功仅表示模型列表可读取，不保证模型调用权限、额度或计费可用。详见[连接指南](getting-started.md#claude)。

## 为什么模型或思考强度没有显示？

先确认当前引擎已经配置，连接地址、认证和模型权限有效。Codex 根据原生模型目录显示模型与支持的思考档位；兼容目录未声明推理能力时不会猜测，菜单可能隐藏。Claude 显示 Haiku / Sonnet / Opus，网关模型 ID 通过映射配置；思考档位以 SDK 报告为准。详见[模型参考](model-discovery.md)。

## 文件和对话保存在哪里？会上传吗？

项目文件位于运行 Codexly 的电脑上。应用数据在该系统用户的 `~/.codexly`，Codex 原生配置与会话默认在 `~/.codex`，Claude 默认在 `~/.claude`。引擎目录可分别由 `CODEX_HOME`、`CLAUDE_CONFIG_DIR` 改写。

“本地工作台”指应用存储与执行位置，不表示离线模型。任务相关请求和上下文仍会发送到所配置的模型服务，MCP 和插件也按各自配置访问外部服务。

## 桌面与 Web 会共享项目吗？换电脑会同步吗？

同机同一系统用户的桌面与 Web 共用应用项目、任务和历史。手机访问 Web 主机的同一份数据；另一台电脑没有自动云同步。界面草稿、分屏偏好不保证跨设备同步，共享存储也不等于同一个运行会话可被两个进程同时控制。

`--codex-home` 只改变 Codex 自身配置、历史和旧数据导入位置，不隔离 `~/.codexly`。详见[本地目录与任务](local-catalog.md)。

## 怎么备份和迁移？

退出桌面应用并停止所有 Web 服务后，备份 `~/.codexly`、实际使用的 Codex / Claude 配置与历史目录，以及项目文件。它们可能包含密钥和对话内容，应妥善保存。恢复后还需确认项目绝对路径、操作系统认证及系统钥匙串可用；仅复制应用目录不保证跨系统凭据和执行上下文可以直接使用。

## 手机为什么打不开？

确保使用 `--lan` 启动，手机与主机在同一可信局域网，并使用终端输出的局域网地址，而不是 `127.0.0.1`。检查主机是否休眠、服务是否仍运行、端口是否被防火墙阻止，以及 Wi-Fi 是否启用设备隔离。端口占用会自动递增，请以实际输出为准。

服务重启后需要重新登录；普通 LAN 启动的随机密码会改变，自启动服务保存的密码可用 `codexly autostart credentials` 查看。不要为解决访问问题将服务直接暴露到公网。

## 关闭窗口后任务和计划还会运行吗？

浏览器页面不是执行主机；只要电脑唤醒且 Web 服务仍运行，关闭页面不会等于关闭服务。桌面版要区分最小化到托盘与真正退出；真正退出应用或停止 Web 服务后，不能继续处理任务或触发计划。具体运行状态以应用为准，休眠不会自动唤醒执行计划。

定时任务显示结果不确定时，先查看关联会话确认实际结果，再删除并重建计划，避免重复执行。

## 如何更新？Windows 便携版只换 EXE 可以吗？

侧栏出现新版本后点击版本号，或到「设置 → 关于」检查更新。Web 全局安装也可重新运行 `npm install --global @bryanhu/codexly@latest`。

Windows 便携版必须关闭应用并用新版 ZIP 的完整解压目录替换旧目录，保留主程序、Claude 宿主和 `runtime`。只换 EXE 会造成资源缺失或版本不匹配。macOS Legacy 与 Modern 有独立更新渠道，升级系统后需手动安装 Modern 才会切换。

## 卸载会删除项目和历史吗？

移除桌面应用或 npm 包不会自动删除项目，也不会清空共享的 `~/.codexly`。删除应用数据会影响同机其他 Codexly 使用端。清理前先备份并停用 Web 登录自启动；系统日志与缓存位置见[桌面安装指南](../desktop/docs/installation.md)。

## 怎样反馈问题？

请提供应用版本、系统及架构、桌面 / 电脑 Web / 移动浏览器、Codex / Claude、复现步骤与脱敏错误。两端均可在「设置 → 关于」导出诊断材料：Web 与移动浏览器下载 JSON，桌面导出 ZIP。Web 终端只保留启动提示和错误，不再持续输出运行日志；必要时运行 `codexly doctor`。详见 [Web 诊断](web.md#排查问题)和[桌面诊断指南](../desktop/docs/diagnostics.md)。原始诊断文件留在本地，仅提交必要的脱敏片段。

普通问题提交到 [Issues](https://github.com/BryanHoo/Codexly/issues)；漏洞请按[安全策略](../SECURITY.md)私密报告。

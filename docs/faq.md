# 常见问题

[文档导航](README.md) · [首次使用](getting-started.md) · [Web 与移动端](web.md)

## 桌面、Web、移动端是什么关系？

桌面版是 macOS、Windows 和 Ubuntu 上的独立应用，内置运行时；Web 版通过 npm 启动本地服务。移动端是 Web 的小屏浏览器界面，不是独立安装包。桌面应用不自动开启局域网服务，需要手机访问时另行启动 `codexly start --lan`。

## 可以只启用一个 ACP 智能体吗？

可以。在「设置 → ACP」启用任意一个智能体即可创建任务。要为已有项目使用另一智能体，请新建任务。

## 如何认证智能体？

在「设置 → ACP」打开智能体详情，按适配器公布的方式认证。使用本机凭据的智能体从服务主机读取配置。[连接指南](getting-started.md#连接-acp-智能体)

## 为什么模型或思考强度没有显示？

先确认当前引擎已经配置，连接地址、认证和模型权限有效。模型和思考档位以当前 ACP 会话公布的配置选项为准。详见[模型参考](model-discovery.md)。

## 文件和对话保存在哪里？会上传吗？

项目文件位于运行 Codexly 的电脑上。应用数据在该系统用户的 `~/.codexly`，Codex 原生配置与会话默认在 `~/.codex`，Claude 默认在 `~/.claude`。引擎目录可分别由 `CODEX_HOME`、`CLAUDE_CONFIG_DIR` 改写。

“本地工作台”指应用存储与执行位置，不表示离线模型。任务相关请求和上下文仍会发送到所配置的模型服务，MCP 和插件也按各自配置访问外部服务。

## 桌面与 Web 会共享项目吗？换电脑会同步吗？

同机同一系统用户的桌面与 Web 共用应用项目、任务和历史。手机访问 Web 主机的同一份数据；另一台电脑没有自动云同步。界面草稿、分屏偏好不保证跨设备同步，共享存储也不等于同一个运行会话可被两个进程同时控制。

## 怎么备份和迁移？

退出桌面应用并停止所有 Web 服务后，备份 `~/.codexly`、实际使用的智能体配置与历史目录，以及项目文件。它们可能包含密钥和对话内容，应妥善保存。恢复后还需确认项目绝对路径、操作系统认证及系统钥匙串可用；仅复制应用目录不保证跨系统凭据和执行上下文可以直接使用。

## 手机为什么打不开？

确保使用 `--lan` 启动，手机与主机在同一可信局域网，并使用终端输出的局域网地址，而不是 `127.0.0.1`。检查主机是否休眠、服务是否仍运行、端口是否被防火墙阻止，以及 Wi-Fi 是否启用设备隔离。端口占用会自动递增，请以实际输出为准。

服务重启后需要重新登录；普通 LAN 启动的随机密码会改变，自启动服务保存的密码可用 `codexly autostart credentials` 查看。不要为解决访问问题将服务直接暴露到公网。

## 关闭窗口后任务和计划还会运行吗？

浏览器页面不是执行主机；只要电脑唤醒且 Web 服务仍运行，关闭页面不会等于关闭服务。桌面版要区分最小化到托盘与真正退出；真正退出应用或停止 Web 服务后，不能继续处理任务或触发计划。具体运行状态以应用为准，休眠不会自动唤醒执行计划。

定时任务显示结果不确定时，先查看关联会话确认实际结果，再删除并重建计划，避免重复执行。

## 如何隐藏桌面状态栏或托盘图标？

在「设置 → 通用」关闭「显示状态栏图标」，即时生效并在重启后保留；重新打开此开关可恢复图标。隐藏图标不会退出应用，关闭窗口仍会最小化到托盘。需要停止后台执行时请真正退出应用。

## 通知为什么会消失？标为已读就会批准操作吗？

进入任务或标为已读后，对应系统通知会自动撤销；问题、审批处理完毕或禁用通知时也会清理相应提醒。同一任务的其他未读提醒不受影响。已读只确认你看过提醒，不会替你批准操作、提交回答或关闭问题；待处理事项仍需在任务中操作。通知历史有容量限制并优先保留未读，完整记录请查看任务历史。

## 如何更新？Windows 便携版只换 EXE 可以吗？

侧栏出现新版本后点击版本号，或到「设置 → 关于」检查更新。Web 全局安装也可重新运行 `npm install --global @bryanhu/codexly@latest`。

Windows 便携版必须关闭应用并用新版 ZIP 的完整解压目录替换旧目录，保留主程序、ACP 宿主和 `runtime`。只换 EXE 会造成资源缺失或版本不匹配。macOS 最低支持 14.5，不再提供 Legacy 安装包或更新渠道。

Windows 安装版若在旧版应用内更新时停滞，先保存工作、结束运行中的任务并退出应用，再从官方 Releases 下载新版安装包重试。0.44.1 起安装器会清理当前安装目录内占用文件的残留运行时。详见[桌面更新说明](../desktop/docs/installation.md#更新)。

## 卸载会删除项目和历史吗？

移除桌面应用或 npm 包不会自动删除项目，也不会清空共享的 `~/.codexly`。删除应用数据会影响同机其他 Codexly 使用端。清理前先备份并停用 Web 登录自启动；系统日志与缓存位置见[桌面安装指南](../desktop/docs/installation.md)。

## 如何诊断 ACP 连接？

在终端运行 `codexly doctor`。它依次检查 Node.js、已启用的 ACP 智能体握手和应用 SQLite。握手仅初始化协议，随后关闭连接。

## 怎样反馈问题？

请提供应用版本、系统及架构、桌面 / 电脑 Web / 移动浏览器、ACP 智能体及其版本、复现步骤与脱敏错误。各端均可在「设置 → 关于」导出整合诊断 ZIP，包含可用的应用诊断文件和 `manifest.json`。Web 终端只保留启动提示和错误，不再持续输出运行日志；必要时运行 `codexly doctor`。详见 [Web 诊断](web.md#排查问题)和[诊断指南](../desktop/docs/diagnostics.md)。分享前检查整个 ZIP，仅提交必要的脱敏片段。

普通问题提交到 [Issues](https://github.com/BryanHoo/Codexly/issues)；漏洞请按[安全策略](../SECURITY.md)私密报告。

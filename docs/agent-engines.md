# Codex 与 Claude Agent

Web（含移动端）与桌面应用统一通过官方 ACP adapter 执行 Codex 和 Claude。应用自己的目录保存任务身份，原厂会话 ID 只用于执行与续聊。新聊天可以选择引擎，创建后引擎固定；切换新聊天的引擎不会修改已有任务。

日常操作参见[首次连接](getting-started.md)、[工作台指南](usage.md)和[Web 局域网接入](web.md)。桌面不自动提供 LAN 服务，手机使用 Web 服务所在机器的账号、工作目录与执行程序。

## 连接与设置

设置页面根据 ACP 握手公布的认证方式与配置选项显示可用操作，不根据厂商名称猜测能力。供应商配置仅在 agent 声明相应接口时提供；未声明时保留原厂配置入口，不伪造连接成功。两个引擎独立启动和诊断，一个不可用不会阻止另一个执行。

默认配置保存在应用的 ACP 设置目录，更新只影响后续新建会话。当前会话的配置选项来自 `session/new`、`session/load` 与配置更新响应，原会话续聊保留自身配置。应用不会把普通默认值变更回写原厂配置文件。旧版应用偏好只读迁移一次，已存在的 ACP 配置优先；原厂认证和策略仍由官方 adapter 读取。

首次会话初始化先保存冻结的配置意图，再绑定原厂会话并应用默认值。配置应用或目录写入失败后，重启沿原会话恢复，不创建替代会话，也不因另一端改变全局默认值而丢失原意图。初始化完成即移除日志内的配置快照。

## 任务、历史与附件

项目、任务侧栏和已缓存历史从本地目录读取，不启动模型。原厂历史通过 ACP `session/list` 发现；打开未缓存的旧任务时，通过原 `sessionId` 加载并重放，不重新发送旧问题。发现仅使用官方接口，不解析厂商私有历史文件。

历史按有界分页加载。重放只有在位置和正文指纹均匹配时才保留已有回合、消息身份及附件，不猜测相似内容的对应关系。搜索只匹配可见正文，返回精确回合和消息锚点；冷历史搜索使用独立受限连接，支持取消并回收迟到连接。近期分页游标可继续读取，历史代际超出保留范围时明确提示刷新。

附件和导出均复核任务、项目与路径归属；宿主只传受控引用。新消息附件随应用历史保存。已有厂商历史能否还原附件内容取决于 agent 通过 ACP 返回的内容，应用不读取任意资源 URI 来补齐缺失数据。

Web 和桌面共享存储锁协议。领取与释放通过 SQLite 的 owner 比较完成；仅确认原进程不存在后回收锁。超时或未知状态明确失败，避免在无法确认写入状态时并发覆盖历史。

## 当前能力边界

支持新建任务、流式消息与工具事件、工具审批、中断、历史读取、原会话续聊、配置选项、附件、排队、搜索、临时文本生成和已确认 ACP 配置的定时任务。可用 UI 以应用已实现的 ACP 能力和 agent 返回选项为准。

当前不公布旧执行器专属的 Goal、Review、分叉、专用压缩、运行中引导、技能管理与反馈上传能力。旧定时任务缺少明确的 ACP 配置时不能自动回退旧执行器，需确认配置后再执行。消息排队仍按原任务和原引擎发送；未知提交结果不会自动重发。

## 桌面分发

`pnpm build:desktop-runtime` 选择锁定的目标平台包并核对摘要、架构和完整布局。Codex 保留官方 vendor 布局及辅助文件，Claude 保留官方 CLI。共享 Bun 宿主只有一个副本，作为 Tauri `externalBin` 参与签名与公证，运行时资源不包含下载缓存或其他架构程序。

Windows 便携版为完整 ZIP，需同时保留主程序、`acp-host.exe` 和 `runtime`。macOS 最低支持 14.5（Apple Silicon / Intel），不再提供 Legacy 安装包、兼容渲染器或更新渠道。桌面用户无需另装 Node.js、Bun 或 CLI；Web 服务要求 Node.js 24+。

## 验证入口

- `pnpm test:acp-host`：编译真实 ACP 宿主并验证传输、配置、目录与事件协议。
- `pnpm build:desktop-runtime` 后执行 `node --test tools/desktop-runtime-bundle.test.mjs`：核对目标资源、sidecar 单份布局和本机程序版本。
- `CODEXLY_REAL_RUNTIME_TEST=1 pnpm exec vitest run packages/provider-acp/src/official-agents.test.ts`：隔离环境下验证官方 adapter 握手。
- `CODEXLY_REAL_ACCOUNT_TEST=1 pnpm exec vitest run src/acp-real-history.test.ts`：使用已配置真实账号验证首发和重启续聊，会消耗模型额度。

本机验证不代替 Windows、Ubuntu、最低 macOS 版本及签名安装包的真机验收。

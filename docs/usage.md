# 工作台使用

[文档导航](README.md) · [English](usage.en.md) · [首次使用](getting-started.md)

本指南适用于桌面端、电脑 Web 和移动浏览器。项目文件、Git 操作和智能体始终位于运行 Codexly 的电脑上。桌面应用提供额外的原生终端、快捷键、独立任务窗口、通知和托盘集成。

## 项目与任务

将一个磁盘文件夹添加为项目。项目根目录是 Git 仓库时可使用 Git 面板；普通子目录不会自动借用父仓库。无需项目上下文时可创建临时任务。

侧栏可置顶任务、查看运行状态、归档历史，并从归档列表恢复或永久删除任务。「已固定」和「运行中」快捷区方便跨项目切换；未查看的完成任务、待审批和运行状态会显示提醒。任务看板提供集中查看任务的入口。

在归档列表选择清理范围，可删除全部归档任务、最后更新于 1/3/6/12 个月前的任务，或自定义日期之前的任务。截止点按当前设备本地日期零点计算，不包含截止日期当天；确认窗口会显示具体日期。清理覆盖全部归档任务，不受当前搜索结果限制，永久删除前请核对范围并按需导出对话。

打开侧栏任务的「更多操作 → 导出对话记录」，可保存 JSON 文件，包含任务信息、全部历史回合、消息、执行条目和附件元数据；无需先在界面加载更早历史。Web 与移动浏览器下载到当前设备，桌面端弹出原生保存窗口。附件二进制不包含在文件中，单次导出上限为 64 MiB；运行中的任务仅导出读取时已收到的内容。此文件用于查阅与处理，不提供导入恢复。

侧栏支持项目与时间线视图切换；时间线按今天、昨天、近 7 天与更早分组，可折叠分组。任务看板与扩展位于侧栏头部，定时任务位于图标区；底部提供设置、通知与帮助入口。通知中心区分未读和已读，可全部标为已读，也可在已读页删除全部已读通知；删除通知不会删除任务。进入任务时自动将该任务的通知标为已读。异步问题到来时通知并标记待回答，回答或关闭后恢复任务状态。

使用搜索查找项目、任务、历史消息和文件；部分搜索入口依赖已启用引擎的能力，详见[搜索参考](global-search.md)。

已读或对应请求已处理时，应用会撤销相应系统提醒；标为已读不等于批准操作或回答问题，同一任务的其他未读提醒仍保留。通知中心自动限制历史容量并优先保留未读，不能代替完整任务历史。

## 发送需求与继续对话

输入需求后选择模型和当前引擎支持的权限、思考强度等选项。可以附加文件或图片，用 `@` 引用项目文件、用 `$` 引用 Skills。具体控件按引擎与模型能力显示；新任务可选择引擎，已有任务不切换引擎。

在「设置 → 常用提示词」保存标题与内容，选择全局或项目范围；聊天输入 `/` 或 `#` 后按标题选择提示词，内容插入光标位置并保留已有输入，不会自动发送。同标题优先使用项目版本。提示词仅保存在当前浏览器或桌面客户端，不随主机任务数据跨客户端同步。输入区空间不足时，模型等配置收进菜单，展开后仍可调整。

任务运行时，查看流式回答、命令输出、工具调用、计划、子代理与文件变更。审批和异步问题需要在当前任务中处理。你可以给运行中的任务补充要求，也可将后续消息加入队列，执行前排序、撤回修改或取消。Claude 的运行中引导、前台中断与后台任务停止各有入口；停止前台不代表所有后台任务都已停止。

审批、问答与 MCP 表单集中在输入框上方，按问题切换并选择选项或填写自定义回答，再提交当前表单。异步问题不一定阻塞任务执行；回答或关闭只处理对应问题。已完成回合中的问题收进执行过程，展开仍可查看。补充要求或回答后，可继续通过运行提示跟踪任务。

发送新问题后，聊天自动定位到本轮问题开头，并保留底部阅读空间；回复增长时逐步使用这部分空间。向上阅读时不会被后台输出拉回，滚动越过的问题会以吸顶摘要显示，点击可回看原文。

连续命令、工具与查看图片操作收进同一操作组。展开后最多显示五行摘要，更多条目在组内滚动；点击条目详情可在独立弹窗查看完整参数和输出，文件变更仍使用差异预览入口。主动滚动或打开详情后暂停自动跟随，滚回底部后恢复；后续回复默认收起操作组，手动展开会保留。已完成回合的文件修改在回复末尾汇总。

历史先加载最近回合，在顶部继续读取更早内容；展开执行过程时才读取对应细节。Claude 可从已完成回复处分叉新会话，也可在命令菜单中压缩上下文。不同引擎的命令与能力以界面为准。

## 分屏与移动视图

桌面应用和电脑浏览器最多支持四个任务分屏。在任务标题栏「分屏布局」选择双、三、四分屏预设，也可通过侧栏任务菜单或聊天空白处右键菜单打开指定方向的分屏。

两端统一使用 `Alt+Shift+方向键`（macOS 的 Alt 为 Option），在「帮助 → 键盘快捷键」可查看当前平台操作。拖动分割线调整大小；每个分屏保留独立草稿与消息队列，项目文件、Git 面板和桌面终端跟随当前聚焦任务。从通知、搜索或看板进入任务会保留分屏布局。

使用任务标题栏的拖动手柄，将当前分屏拖到另一个分屏，可交换两者的位置；拖动时的目标提示帮助确认落点。

移动端保持单任务视图，通过侧栏切换项目与任务，按需打开文件、变更和设置面板；不提供桌面原生终端或全局快捷键。连接方式见 [Web 与移动端](web.md)。

## 文件与预览

在右侧项目面板中浏览文件，点击后在中栏标签打开代码、Markdown、图片或 PDF，文件树保持原位。文件差异、批量审核与提交详情也进入中栏；点击「聊天」返回会话。图片支持缩放和拖动，聊天附件继续使用对应预览。

拖动文件标签调整顺序，右键标签或打开「标签操作」菜单可固定、移动和批量关闭；手机也可通过菜单操作。常规批量关闭保留固定项，关闭前会保存编辑，保存失败时保留标签与草稿。聊天标签始终保留在首位。

文件标签工具栏支持「与聊天左右对照」「与聊天上下对照」，拖动分割线调整大小，再次点击已选中的对照按钮恢复单栏。只有聊天时隐藏标签栏；从任务入口切换任务时回到聊天，并保留已打开的文件标签。每个任务分屏独立管理文件标签；手机上使用单组标签，打开文件后自动收起覆盖内容的侧栏。详见[工作区设计与操作](document-workspace.md)。

从手机或其他局域网设备访问时，不能预览的文件可通过「下载」保存到当前设备，再用本机应用打开；文件树、聊天文件链接和搜索结果中的「系统默认」会先显示下载提示，点击后才传输文件。本机 Web 与桌面端仍可调用主机上的应用打开文件。

打开文本源码即可编辑，Markdown 需先切换到源码模式。支持最大 2 MiB 的 UTF-8 文本，保留原换行和 BOM；其他文件只读。失焦、离开文件或切换窗口时自动保存，`⌘/Ctrl+S` 可手动保存，也可撤销和重做。

保存失败或外部修改冲突时，保留当前窗口草稿并提供恢复操作。草稿保存在内存，刷新、强制退出或崩溃后不保证恢复；离开前确认保存状态。详见[文本文件编辑](text-file-editing.md)。

## Git 与 worktree

在变更面板审阅差异、选择文件并编辑提交信息，执行「提交」或「提交并推送」；已有本地提交可单独推送，无需制造新的文件变更。推送失败不会撤销已经保存的本地提交，修复认证或连接后重试推送即可。

顶部工具栏提供远端配置、发布分支、获取更新和仅快进拉取。提交信息草稿按当前设备、项目、worktree 与分支保存。Git 使用运行 Codexly 的电脑上的身份和远端认证，手机上的 Git 账号不会自动用于主机。

从输入区下方的分支菜单选择或新建 worktree，再在该目录中发送第一个消息。原会话保持原目录，新任务使用选中的 worktree。依赖与忽略的环境文件不会自动复制；合并冲突需在外部 Git 工具处理。详见 [Git 操作指南](git-workflow.md)。

## 定时任务

在「定时任务」创建计划，选择项目、需求、引擎与模型，配置重复规则并预览后续执行时间。Codex 与 Claude 都可用于计划；只配置 Claude 时自动使用 Claude。修改计划引擎影响后续执行，已经创建的聊天保留原引擎。

计划在提供服务的电脑上执行，电脑须保持唤醒，桌面应用或 Web 服务须运行。若执行结果不确定，系统会暂停后续运行；先检查关联对话，确认实际结果后再删除并重建计划。显示清理中的任务会自动重试清理，不会因此再次执行需求。

## 扩展与设置

桌面端可在「设置 → 通用 → 显示状态栏图标」控制系统状态栏或托盘图标，默认显示，修改立即生效并跨重启保留。隐藏图标不退出应用，也不改变关闭窗口后最小化到托盘的行为；需要停止后台任务时请真正退出应用。Web 和移动浏览器不提供此开关。

在扩展中心选择 Codex 或 Claude，分别管理 Skills、MCP 和官方插件，并注意全局与项目范围。不同引擎提供的操作不同；Claude 当前支持查看、启停和移除已有 MCP 配置，新增 MCP 需通过其原生配置完成。扩展配置改变后，新建会话以完整加载。

通过搜索和筛选定位扩展，先选择全局或当前项目，再执行对应范围的操作。Claude 支持安装、启停、更新和卸载官方目录中的插件；项目 Skills 与 MCP 列表仅展示该项目的配置。Codex 项目 MCP 只读。应用已移除第三方技能市场入口，本地 Skills 仍可管理；开关表示启用配置，不代表 MCP 已实时连接。

模型、思考强度、权限和上下文窗口按引擎配置。模型默认值用于新任务，已有会话保留自己的选择；窗口声明不会扩大模型或服务商的真实容量。Claude 权限模式不等同于 Codex 的系统沙盒，扩展配置也不在两种引擎间自动复制。详见[引擎参考](agent-engines.md)与[上下文设置](model-context-window.md)。

## 用量统计

在「设置 → 用量统计」按年份和引擎查看 Token 总量、活跃天数、趋势与年度热力图，选择日期查看当天用量最高的 50 项任务。日期按 UTC 归属；手机可横向滚动热力图。统计只记录功能启用后观测到的实际新增用量，不回填旧历史，也不代表剩余额度、费用或官方账单。详见[用量统计参考](usage-statistics.md)。

## 数据与多端使用

同机同一系统用户下，桌面与 Web 共用 `~/.codexly` 中的项目、任务和历史；手机访问 Web 主机的数据。另一台电脑不会自动同步这些本地目录，也不应将同机共享理解为可同时控制同一执行会话。

多个浏览器连接同一个 Web 服务时，项目待办与异步问题会同步；重新连接或回到页面会刷新状态。草稿、分屏等界面偏好不保证跨设备同步。备份及迁移见[常见问题](faq.md)。

## 开发前检查

- 阅读 [.superwork/spec/guides/index.md](../../guides/index.md)
- 涉及真实后端接入时同步阅读 [Tauri 后端开发规格](../../src-tauri/backend/index.md)
- 确认变更属于应用装配、功能域、共享基础设施、协议契约或 mock 传输中的单一职责
- 队列编辑必须先撤回服务端排队项，再将文字、图片和附件完整恢复到 Composer；禁止让旧排队项与编辑草稿共享附件生命周期
- 附件占位信息必须与可见正文分离
- 队列启动按钮对最近一次同目标失败保留原幂等键，成功后释放；使用 ref 保存尝试身份，不用渲染状态保存执行结果。旧请求成功不能清除另一目标的新尝试，持久化恢复由原生另行提供。
- Git 操作失败时，后端必须返回稳定错误码并保留原始错误；前端按当前语言显示可操作提示，同时将原始错误写入诊断日志。

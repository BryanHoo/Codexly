# Provider Runtime Manager 实施计划

## 目标

在不打包 Provider Sidecar 的前提下，实现运行时发现、兼容性检查、应用私有按需安装、升级和
回退，并保持 WebView 无通用进程执行权限。

## 阶段一：运行时契约与发现

- 定义 Provider 运行时来源、版本要求、检测状态和稳定 IPC 事件。
- 实现用户配置路径、应用私有目录、`PATH` 和平台常见目录的候选发现。
- 为版本命令增加超时、输出上限、绝对路径解析和缓存失效策略。
- 对 Codex `0.149.0` 执行版本匹配和 `app-server` 初始化能力探测。

验收：缺失、版本不兼容、探测失败和可用状态均能稳定区分，检测不阻塞应用主界面。

## 阶段二：应用私有按需安装

- 定义受信任的 Provider 发布元数据和目标平台映射。
- 实现下载去重、进度事件、临时目录、SHA-256 与签名校验。
- 将通过验证的运行时原子安装到 `appData/providers/<provider>/bin/<version>/`。
- 在用户取消、网络中断、磁盘不足或校验失败时保留现有可用版本。

验收：应用不调用全局包管理器，失败安装不留下可启动的半成品，不修改系统 `PATH`。

## 阶段三：版本切换与恢复

- 将 CodeAgent Provider 适配器绑定到已验证的精确运行时版本。
- 新版本完成安装和能力探测后再原子更新 `active.json`。
- 启动失败时回退到上一个可用版本，并输出可恢复诊断。
- 清理不再使用的旧版本和过期下载，同时保留最近一个回退版本。

验收：升级过程可中断、可恢复，系统安装永不被覆盖或降级。

## 阶段四：Provider 扩展

- 为 Claude Code 实现独立的版本解析、能力探测、官方安装源和完整性校验。
- 将通用编排与 Provider 专属策略分离，不复用认证、配置和会话目录。
- 适配器具备多版本协议回归测试后，再评估从精确版本扩展为兼容版本范围。

验收：增加 Provider 不增加 CodeAgent 基础安装包中的外部运行时体积。

## 发布门禁

- 验证 Windows x64、macOS Apple Silicon 和 Ubuntu x64 的发现及安装路径。
- 验证官方来源、checksum、签名和许可证或服务条款。
- 验证 GUI 启动环境缺少终端 `PATH` 时仍能发现常见安装位置。
- 验证离线、代理、限速、磁盘不足、权限不足和杀毒软件拦截场景。
- 验证运行时不会在应用控制之外自动更新到不兼容版本。

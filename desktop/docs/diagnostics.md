# 使用诊断日志排查问题

## 导出 ZIP

1. 记录故障发生时间、所选 Agent、执行的操作和实际结果。
2. 在「设置 → 关于」导出诊断 ZIP。宿主或 Agent 启动失败时也可使用。
3. 查看 `manifest.json` 中的应用版本、系统、架构和运行时。使用 `logs/` 下的日志和 `metrics/runtime.json` 的运行指标定位故障。

Web 和移动浏览器下载的归档包含 `application.json`，其中汇集近期浏览器异常、版本及服务端快照。下载链接绑定发起导出的配对会话，有效期为 5 分钟，并可领取一次。

## 定位问题

- 启动失败时，按时间查看 `warn` 和 `error`，检查程序退出或握手失败的记录。Agent 的安装或认证状态见「设置 → ACP」。
- 聊天失败时，使用项目和任务标识匹配错误与当时的操作。回合耗时、连接和事件指标可用于定位传输问题。
- 分享前检查归档中的账户标识、文件路径和错误消息。安全问题使用仓库的私密报告渠道。[安全报告](../../SECURITY.md)

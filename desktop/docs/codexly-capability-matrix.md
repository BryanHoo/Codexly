## 使用端

| 能力                                         | 桌面应用                       | 电脑 Web            | 移动浏览器          |
| -------------------------------------------- | ------------------------------ | ------------------- | ------------------- |
| Codex / Claude 任务                          | 支持，macOS Legacy 仅 Codex    | 支持                | 支持，连接 Web 主机 |
| 流式聊天、审批、提问、附件与队列             | 支持                           | 支持                | 支持                |
| 项目、任务看板与定时任务                     | 本机执行                       | 服务端执行          | 操作 Web 主机       |
| 文件预览与文本编辑                           | 本机文件                       | 服务端文件          | 服务端文件          |
| Git、分支、worktree、提交与推送              | 本机 Git                       | 服务端 Git          | 服务端 Git          |
| 全局搜索                                     | 按可用引擎检索                 | 按启用引擎检索      | 同 Web，适配小屏    |
| 任务分屏                                     | 最多四个                       | 桌面视图最多四个    | 单任务视图          |
| 原生项目终端、全局快捷键、托盘、独立任务窗口 | 支持                           | 无桌面原生集成      | 无桌面原生集成      |
| 手机连接入口                                 | 需另启 Web 服务                | `--lan` 开启        | 浏览器访问 LAN 地址 |
| 登录后启动                                   | 应用设置                       | `codexly autostart` | 依赖主机服务        |
| 安装环境                                     | 内置运行时，无需 Node.js / Bun | 主机需 Node.js 24+  | 兼容浏览器          |

桌面包支持 Windows 10/11 x64、Ubuntu 24.04+ x64、macOS Modern 14.5+ Apple Silicon / Intel，以及 macOS Legacy 12.4+ Intel。安装包与平台提示见[安装指南](installation.md)。

## 引擎

| 能力                           | Codex                             | Claude                                                   |
| ------------------------------ | --------------------------------- | -------------------------------------------------------- |
| 配置与认证                     | ChatGPT 登录或 Responses 兼容 API | 复用受支持本机凭据或 Messages 兼容 API；无应用内账号登录 |
| 模型与思考强度                 | 原生模型目录与能力                | SDK 能力，Haiku / Sonnet / Opus 与可选网关映射           |
| 任务执行、历史恢复、审批与提问 | 支持                              | 支持                                                     |
| 计划、子代理与上下文用量       | 原生事件投影                      | SDK 事件与持久摘要投影                                   |
| 队列、运行中补充要求           | 支持                              | 支持；前台中断与后台停止分开控制                         |
| 会话分叉与压缩                 | 按原生命令与界面能力              | 原生会话分叉与压缩                                       |
| Git 提交说明与定时任务         | 支持                              | 支持，无需配置 Codex                                     |
| 搜索对话正文                   | 原生历史搜索，必要时回退分页匹配  | 应用保存的可见问答摘要，不检索完整工具正文               |
| 扩展                           | 原生 Skills、MCP 与插件接口       | 原生 Skills、MCP 与官方插件；当前不提供新增 MCP 表单     |
| 权限                           | 审批策略与沙盒                    | SDK 工具权限模式，不等同于操作系统沙盒                   |
| Goal、Review、Guardian         | 按 Codex 专属入口                 | 不映射为 Claude 功能                                     |

模型、扩展和权限选项以当前服务、模型与引擎返回的能力为准。配置两种引擎后可在新任务选择；已有任务绑定引擎，不因修改新任务默认值而改变。

## 执行与存储边界

Web 浏览器通过 HTTP / WebSocket 访问本地服务，再由各引擎适配器执行。桌面通过 Tauri invoke / Channel 进入原生层：Codex 走 Rust 的 App Server stdio 链路，Claude 走共用适配器编译的独立 stdio 宿主。桌面执行不依赖另行启动的 Web 服务。

同机同一系统用户的桌面与 Web 共用 `~/.codexly` 项目、任务和历史；移动浏览器访问 Web 主机。引擎配置与会话仍由 Codex / Claude 原生目录维护。共享存储不提供跨电脑云同步，也不表示两个独立进程可以同时控制同一运行会话。

运行时随桌面包分发、按需启动，缺失或损坏时修复安装；不再按旧文档在首次启动下载。Web 继续使用 npm 依赖。项目相关上下文会发给配置的模型服务，“本地”不代表离线推理。

# Codexly

[English](README.md) | 简体中文

Codexly 是本地 AI 编程工作台，提供桌面应用和 Web 版。它将编程任务、对话、项目文件与 Git 操作集中在一处。桌面版适合在本机持续工作；Web 版在本地运行，可通过浏览器从电脑或可信局域网中的移动设备访问。项目文件和 Codex 运行时始终留在运行 Codexly 的电脑上。

目录和任务由 Codexly 自行管理，每个目录对应一个磁盘文件夹；旧数据首次启动时自动导入，详见[本地目录与任务](docs/local-catalog.md)。

## 获取 Codexly

| 版本   | 适用场景                                           | 开始使用                                                                                                                                 |
| ------ | -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 桌面版 | 原生工作台、集成终端、独立任务窗口、系统通知与托盘 | [下载 Windows、Ubuntu 或 macOS 安装包](https://github.com/BryanHoo/Codexly/releases)，按[桌面安装指南](desktop/docs/installation.md)安装 |
| Web 版 | 本机浏览器工作台，或从可信局域网内的其他设备访问   | 安装 Node.js 24+，按[Web 版启动步骤](#启动-web-版)运行                                                                                   |

桌面安装包支持 Windows 10/11 x64、Ubuntu 24.04+ x64、macOS 14.5+（Apple Silicon / Intel），并提供 macOS 12.4+ Intel 的 Legacy 版本。安装步骤与各平台的系统提示见[安装指南](desktop/docs/installation.md)。桌面版首次启动会自动安装并校验应用私有的 Codex 运行时。

## 主要功能

- 实时查看任务回复、命令、审批、推理摘要和文件变更，查看文件编辑耗时与完成汇总，并用持久化队列安排后续消息。
- 优先加载最近的会话历史，顶部按需读取更早回合，展开过程后独立加载执行条目；长代码预览共用渲染与有界高亮。详见[会话加载与性能](docs/conversation-performance.md)。
- 在 Web 桌面浏览器与桌面应用中并行打开最多四个任务，各分屏保留独立草稿与消息队列；文件和 Git 面板跟随当前聚焦任务，Web 移动端保持单任务视图。
- 从任务标题栏的「分屏布局」选择双、三、四分屏的自适应、横排、竖排、主辅或田字布局；保留当前会话，其余分屏打开新建页。仅桌面视图提供此入口。
- 拖动分割线调整任务分屏尺寸，从任务标题栏新建任务；收起输入框后仍可查看当前模型与思考量。
- 在桌面或移动端的项目文件源码预览中直接编辑文本，支持撤销重做，并在离开编辑区或切换窗口时自动保存。
- 阅读流式 Markdown 回复并复制原始文本；缩放、拖动消息图片、项目图片与壁纸，或以原始尺寸查看。
- 直接预览聊天附件、文件链接与项目文件树中的 PDF。
- 查看 Markdown 回复中嵌入的任务本地图片，并打开图片预览。
- 使用助手回复中的文件引用、代码审查评论与后续建议；点击建议后可在输入框继续编辑。
- 为任务选择模型、思考量、快速模式、审批策略和文件访问范围，并在全局设置中配置[上下文窗口](docs/model-context-window.md)。
- 新建项目及目录，跨项目搜索任务、历史消息和文件；检查变更、管理分支与 worktree，选择文件后提交或提交并推送，也可独立推送已有提交；详见 [Git 操作指南](docs/git-workflow.md)。Git 操作仅作用于项目根目录对应的仓库，普通子目录不会借用父仓库。 Web（含移动端）与桌面端均可在输入框底部分支菜单创建、选择 worktree；新工作树统一存放在主项目的 `.worktree/` 下。发送消息时再使用输入框中的 Claude / Codex、模型等配置创建任务，任务仍归属原项目。
- 在侧栏「已固定」与「运行中」快捷区切换任务，未查看的完成任务优先于待审批与运行任务展示，并保留在分组总数中，查看后清除完成提醒；可折叠预览或打开完整列表，项目收起时仍可访问。
- 通过侧栏任务的项目标签识别任务来源；项目收起时仍显示未读完成、等待审批或运行状态。
- 管理 Skills、插件、MCP 服务、项目、归档任务、通知与定时工作；刷新官方插件可同步状态，并提示部分失败。
- 在「设置 → 智能体配置 → 历史文件存储」手动请求后台压缩超过 7 天未写入的历史；Web 作用于服务端，桌面端作用于本机。共用历史目录的其他 Codex 客户端需支持压缩格式。

**桌面版**提供原生项目终端、全局快捷键、独立任务窗口、托盘集成和应用私有 Codex 安装。支持 Windows、Ubuntu 和 macOS；在通用设置中可启用登录系统后自动启动。完整功能与更新方式见[桌面版指南](desktop/README.md)。

**Web 版**在本机运行服务并由浏览器访问，支持手机等设备从可信局域网接入、任务看板、Mermaid 图表和自定义工作台背景。Web 版通过 `@openai/codex` 自带 Codex CLI `0.163.0`；使用 `--codex-bin <path>` 或 `CODEXLY_CODEX_BIN` 指定外部版本时，版本必须满足 `>=0.163.0,<0.164.0`。

连接同一 Web 服务的浏览器与设备会同步项目待办和异步问答变更；断线重连或页面恢复可见时刷新状态。

在支持分屏的工作台中，可从侧栏任务菜单打开任务分屏，也可在聊天空白处右键选择向上、向下、向左或向右分屏。快捷键为 macOS `⌘+⌥+方向键`，Windows / Linux `Ctrl+Alt+方向键`；最多四个分屏。

拖动分割线可调整相邻分屏尺寸；从通知、搜索或任务看板跳转时保留分屏布局。

## 启动 Web 版

需要 Node.js >=24.0.0，以及 Chrome/Chromium 116+、Firefox 124+ 或 Safari 17.4+。

无需安装，直接运行最新版本：

```bash
npx --package @bryanhu/codexly@latest codexly start
```

Codexly 会自动打开浏览器。若未打开，请访问终端输出的地址；默认地址为 `http://127.0.0.1:3210`。使用期间需保持终端运行，按 `Ctrl+C` 停止。

运行 `codexly --version` 查看安装版本，或使用 `codexly <command> --help` 查看命令专属选项。

可以在同一启动目录或同一 Codex Home 下同时运行多个 Web 实例；端口占用时自动递增。启动目录不决定应用内部配置或临时任务目录：临时任务默认使用用户主目录，显式指定 `--workspace` 时使用首个工作区。使用不同的 `--codex-home <目录>` 可隔离数据。

首次启动时，使用 ChatGPT 登录，或配置兼容 Responses API 和 `GET /models` 的 OpenAI-compatible 服务。
自定义 Provider 会发现可用模型，保留目录声明的能力与思考档位；未声明推理能力时隐藏思考强度菜单。详见[模型与思考强度](docs/model-discovery.md)。

经常使用时可以全局安装：

```bash
npm install --global @bryanhu/codexly@latest
codexly
```

安装命令使用 npm 默认源（未自行配置时为官方源），复用 npm 缓存并重新校验过期的包元数据。

## Web 登录自启动

全局安装后，通过 CLI 配置当前用户登录系统时自动运行。支持 macOS、Windows 和带 systemd 用户服务的 Ubuntu；本机与 LAN 模式均不自动打开浏览器。

```bash
# 本机模式；下次登录启动
codexly autostart enable

# LAN 模式；同时立即启动
codexly autostart enable --lan --now

codexly autostart status
codexly autostart credentials
codexly autostart logs
codexly autostart restart
codexly autostart disable
```

`enable` 保存本次提供的启动参数，默认本机模式和端口 3210；重复执行会更新同一个登录项。省略 `--now` 时，当前运行实例在重启或下次登录后应用新配置。端口占用会递增，请以 `status` 输出的实际地址为准。LAN 密码首次生成后保存复用，通过 `credentials` 显式查看；服务重启后需重新认证。

需要稳定的全局 npm 安装，不能从 `npx` 临时缓存登记。Node/npm 安装路径变化后运行 `codexly autostart repair --now`；卸载 npm 包前运行 `codexly autostart disable`。普通前台启动可用 `codexly start --no-open` 禁止打开浏览器。

配置位置、环境变量、Linux linger 限制和各系统故障排查见 [Web 登录自启动指南](docs/web-autostart.zh-CN.md)。

## 使用 Web 版

不依赖项目时，直接选择“新建任务”。处理仓库时，先添加一个运行端文件夹作为项目目录，再创建任务，并按需附加文件、图片、项目引用或 Skills 后提交需求。归档的任务可以从项目任务列表中恢复或永久删除。

Git 变更面板顶部显示分支、推送目标及待同步数量，提供远端配置、发布分支、获取更新、仅快进拉取与独立推送。底部编辑提交信息，主按钮执行「提交」，「更多 Git 操作」提供「提交并推送」。草稿按项目、worktree 和分支保存在当前设备；AI 生成可撤销，推送失败会保留本地提交并可单独重试。首次推送可通过「发布分支」建立上游，历史中可查看未推送标记。

任务控件用于设置模型、思考量、快速模式、审批方式和文件访问范围。通知偏好与项目最近一次完整设置会保存给后续任务。右侧检查器提供项目文件、来源、代码变更、Git 历史、审查和提交操作。即使从其他设备打开界面，项目目录和文件仍来自运行 Codexly 的电脑。

定时任务显示“结果未知”时会暂停后续运行，请先查看关联对话；确认后可删除该计划并重新创建。“已启动，正在收尾”会自动重试清理，无需再次运行。

打开项目文本文件的源码预览即可编辑，Markdown 需先切换到源码模式。编辑区失焦、离开文件或切换窗口时自动保存，也可按 `⌘/Ctrl+S` 手动保存。支持最大 2 MiB 的 UTF-8 文本，并保留换行与 BOM；更大或不支持的文件保持只读。保存失败或发生外部修改冲突时，当前窗口保留草稿并显示恢复操作。草稿仅保存在内存中，刷新、强制退出或崩溃后不保证恢复。

## Web 局域网访问

在可信局域网中启动：

```bash
codexly start --lan
```

终端会输出局域网地址和随机访问密码。常用选项如下：

| 选项                        | 用途                                                 |
| --------------------------- | ---------------------------------------------------- |
| `--port <port>`             | 指定起始端口；端口被占用时自动尝试后续端口           |
| `--lan-password <password>` | 设置 16 至 128 位密码，必须包含大小写字母和数字      |
| `--allowed-host <domain>`   | 允许精确的反向代理域名；多个域名可重复传入           |
| `--session-ttl <duration>`  | 设置固定会话期限，如 `12h`；省略时持续到 Server 重启 |
| `--workspace <path>`        | 限制项目选择的绝对根目录；多个根目录可重复传入       |

密码含 Shell 特殊字符时请使用引号。局域网模式使用未加密 HTTP，只能用于可信网络，禁止直接暴露到互联网。重启 Codexly 会使随机配对码和全部会话失效；显式设置的固定密码保持有效。

## Web 诊断与更新

启动、Codex 或本地数据检查失败时运行 `codexly doctor`。使用 `codexly --help` 查看完整命令，`codexly start --help` 或 `codexly doctor --help` 查看对应选项，`codexly --version` 查看版本。

交互式启动和“设置 > 关于”会检查新版本。侧栏出现更新提示后，点击版本号即可查看更新日志并安装更新。内置更新会并行探测官方源和镜像源，优先使用最先成功响应的源，失败后切换另一个源；同一次更新的包下载和依赖安装复用选源结果及用户的 npm 缓存。若选中的镜像仍在同步，新版本可能稍晚显示。全局安装也可以通过以下命令更新：

```bash
npm install --global @bryanhu/codexly@latest
```

如果 Linux 上的旧版本通过 `sudo npm install --global` 安装到系统目录，首次升级到支持提权更新的版本时需要手动执行一次上述命令并在前面加上 `sudo`。后续内置更新会在需要时请求 `sudo` 权限。
